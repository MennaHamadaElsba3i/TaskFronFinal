# Task Dashboard

A React-based task management dashboard for tracking tasks, managing inventory, and monitoring operations.

## Features
- Task search, filtering, and sorting
- Bulk task actions
- Inventory management with input validation
- Notes and auto-save
- Undo/Redo actions
- Local data persistence
- Automated tests

## Tech Stack
- React
- Vite
- TanStack Query
- Vitest

## Getting Started

```bash
npm install
npm run dev
```

## Testing

```bash
npm test
```

## Data Storage

Task data is stored in the browser's `localStorage`. Data is local to each browser and is not shared across users.
